    🛡️ About link security
    
          
    Links are signed with HMAC-SHA256 using the SIGNING_KEY constant near the top of this file's script. A link that was edited or made with a different key shows “Access Denied”. To invalidate every old link, change the key and re-upload the file. For best protection, change it from the default before you share links.
    
          
    Anyone who can open a link can decode the questions inside it, so don't use this for secret exams.
